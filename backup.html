ROUTINE NOTE — DATA

データの守り方

組んだ構成も、通しの記録も、撮った映像も、消したくないから作っているものです。 このページは、それがどこに保存されていて、どうすれば失わずに済むかをまとめたものです。

最終更新: 2026年7月27日 ／ ベータ版
先に結論だけ

練習の記録がたまってきたら、「設定 → 完全バックアップ → ZIPで書き出す」を実行して、 そのファイルをiCloudやパソコンなど端末の外へ置いてください。
映像まで含めて丸ごと残せるのは、この方法だけです。

1. どこに保存されているか

ルーティンノートは、あなたが作ったものをお使いの端末のブラウザの中に保存します。 開発者のサーバーへ勝手に送ることはありません。

ログインすると、そこに同期が加わります。同期されるものとされないものは、はっきり分かれています。

ログインすると同期されるもの この端末だけに残るもの
ルーティンの構成（技・移行の並び、キュー、長さ）
通しの記録（崩れた場所、日付、メモ）
技と音源の見出し情報（名前など） 		技の動画ファイル
音源ファイル
通しの演技映像
アプリの設定（言語・画質など）

つまりログインしていても、映像と音源は守られません。ここが誤解されやすいところです。 映像まで残したい場合は、あとで説明する完全バックアップが必要です。

映像の同期（クラウド保存）は、ベータ版のあとの段階で対応する予定です。

2. データが消えるのはどんなときか

起きること 防げるか
ブラウザの「履歴とWebサイトデータを消去」を実行した 防げません
端末の空き容量が減り、ブラウザが自動で消した 「データの保護」で防げます
iPhoneで長期間ひらかず、保存データが消えた ホーム画面に追加すれば、ほぼ防げます
プライベートブラウズで使っていた タブを閉じると消えます
端末を失くした・壊れた・機種変更した ログインなら構成と記録は戻ります
映像はバックアップが必要です

3. 三重に守る

ひとつの方法ですべては守れません。役割の違う3つを重ねます。

  1. データの保護（自動） 容量不足でブラウザに勝手に消されないようにする仕組みです。 記録ができた時点でアプリが自動で有効にしますので、操作は要りません。 状態は「設定 → データ → データの保護」で確認できます。
    ただし、ご自身でブラウザのデータを消した場合は防げません。
  2. ログイン（端末をまたぐ保険） 構成と練習の記録が、ログインした端末どうしで同期されます。 端末が壊れても、別の端末でログインすれば戻ってきます。
    映像・音源は同期されません。
  3. 完全バックアップZIP（唯一の完全な保険） 動画・音源・演技映像まで含めて、1つのファイルに書き出します。 丸ごと残せるのはこれだけです。書き出したファイルは、必ず端末の外へ置いてください。

4. 完全バックアップの取り方

  1. 設定 → 完全バックアップ → 「ZIPで書き出す」 映像の量によっては数分かかります。画面はそのままにしておいてください。
  2. できたファイルを端末の外へ移す iCloud Drive、Googleドライブ、パソコンなど。 同じ端末の中に置いたままでは、端末を失くしたときに一緒に失われます。
  3. 「ZIPを検証する（復元しない）」で中身を確かめる 書き出したファイルが壊れていないかを、復元せずに調べられます。 ファイル1つずつの中身を照合するので、いざというとき本当に戻せるかがここで分かります。 取ったつもりのバックアップが壊れていた、という事故を防ぐための手順です。

目安として、大きな構成変更のあとと、大事な通しを撮ったあとに取っておくと安心です。

5. 復元するとき

ログイン中の復元にはご注意ください

ログインした状態でZIPから復元すると、その内容が他の端末にも同期されます。 バックアップに入っていないルーティンや記録は、他の端末からも消えます。
この端末だけを戻したいときは、先にログアウトしてから復元してください。

復元は「設定 → 完全バックアップ → ZIPから復元する」です。 復元の前にファイルの中身をすべて照合し、ひとつでも壊れていれば、途中で止めて何も置き換えません。 中途半端に一部だけ書き換わることはありません。

6. 軽量バックアップ（JSON）との違い

　 完全バックアップ（ZIP） 軽量バックアップ（JSON）
構成・記録 入ります 入ります
動画・音源・演技映像 入ります 入りません
ファイルの大きさ 大きい とても小さい
向いている用途 本命の保険。機種変更 こまめな控え

7. 機種変更するとき

  1. 古い端末で完全バックアップZIPを書き出し、端末の外へ置く
  2. 新しい端末でこのページを開き、ホーム画面に追加する
  3. ログインしている場合は、まずログインする（構成と記録が戻ります）
  4. 映像も戻したい場合は、ログアウトしてからZIPを復元し、そのあと改めてログインする
覚えておいてほしいこと

保存先はブラウザごと・サイトごとに分かれています。 別のブラウザで開くと、同じ端末でも中身は空です。いつも同じ入り口から開いてください。 ホーム画面に追加しておくと、これを間違えずに済みます。

8. うまくいかないとき

  • 書き出しが終わらない … 映像が多いと時間がかかります。画面を切り替えずにお待ちください
  • 復元で「壊れています」と出た … 転送の途中でファイルが欠けた可能性があります。書き出しからやり直してください
  • 記録が消えていた … これが一番知りたい不具合です。下のボタンからご連絡ください
