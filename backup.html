ROUTINE NOTE — DATA

データの守り方

最終更新: 2026年7月28日 ／ ベータ版

1. アカウントと同期

アカウントを作らない場合、データはこのブラウザの中だけに保存されます。 開発者のサーバーへ送られることはありませんが、他のデバイスとは共有されず、 ブラウザの保存データを消すと失われます。

アカウントを作成すると、動画・音源以外のデータはオンライン上で管理されます。 そのため、他のデバイスでも同期して使えます。

動画・音源に関するデータは、現在のところオンラインでは同期されません。 他のデバイスへ動画や楽曲まで引き継ぎたい場合は、ZIPでの書き出しと読み込みを行ってください。

動画のクラウド保存は、ベータ版のあとの段階で対応する予定です。

2. ログインしない場合のリスク

非ログイン状態では、データが失われる可能性が高くなります。

作ったものの控えが、このブラウザの中にしか無いためです。 下のどれか一つが起きただけで、組んだ構成も練習の記録も戻せなくなります。

起きること 非ログイン ログイン中
ブラウザの「履歴とWebサイトデータを消去」を実行した すべて失われます 構成と記録は戻ります
端末の空き容量が減り、ブラウザが自動で消した すべて失われます 構成と記録は戻ります
iPhoneで長期間ひらかず、保存データが消えた すべて失われます 構成と記録は戻ります
プライベートブラウズで使っていた タブを閉じると
消えます		 構成と記録は戻ります
端末を失くした・壊れた・機種変更した すべて失われます 構成と記録は戻ります

ログインしておけば、少なくとも構成と練習の記録は別のデバイスから戻せます。 ただし動画・音源はログインしていても戻りません。そこまで守るには完全バックアップZIPが必要です。

なお、2番目は自動で有効になる「データの保護」で起きにくくなります。 3番目はホーム画面に追加しておけば、ほぼ避けられます。

3. 完全バックアップの取り方

  1. 設定 → 完全バックアップ → 「ZIPで書き出す」 映像の量によっては数分かかります。画面はそのままにしておいてください。
  2. できたファイルを端末の外へ移す iCloud Drive、Googleドライブ、パソコンなど。 同じ端末の中に置いたままでは、端末を失くしたときに一緒に失われます。
  3. 「ZIPを検証する（復元しない）」で中身を確かめる 書き出したファイルが壊れていないかを、復元せずに調べられます。 ファイル1つずつの中身を照合するので、いざというとき本当に戻せるかがここで分かります。 取ったつもりのバックアップが壊れていた、という事故を防ぐための手順です。

目安として、大きな構成変更のあとと、大事な通しを撮ったあとに取っておくと安心です。

4. 復元するとき

ログイン中の復元にはご注意ください

ログインした状態でZIPから復元すると、その内容が他の端末にも同期されます。 バックアップに入っていないルーティンや記録は、他の端末からも消えます。
この端末だけを戻したいときは、先にログアウトしてから復元してください。

復元は「設定 → 完全バックアップ → ZIPから復元する」です。 復元の前にファイルの中身をすべて照合し、ひとつでも壊れていれば、途中で止めて何も置き換えません。 中途半端に一部だけ書き換わることはありません。

覚えておいてほしいこと

保存先はブラウザごと・サイトごとに分かれています。 別のブラウザで開くと、同じ端末でも中身は空です。いつも同じ入り口から開いてください。 ホーム画面に追加しておくと、これを間違えずに済みます。

5. うまくいかないとき

  • 書き出しが終わらない … 映像が多いと時間がかかります。画面を切り替えずにお待ちください
  • 復元で「壊れています」と出た … 転送の途中でファイルが欠けた可能性があります。書き出しからやり直してください
  • 記録が消えていた … これが一番知りたい不具合です。下のボタンからご連絡ください
