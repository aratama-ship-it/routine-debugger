ROUTINE NOTE — BETA

隱私權政策

最後更新：2026年7月28日 ／ 本服務目前為Beta版
本中文版僅供參考。政策的解釋以日文版為準。

「Routine Note」(以下稱「本App」)是用來記錄與分析表演全套練習的網頁應用程式。 本App對使用者資訊的處理，規定如下。

首先想讓你知道的事
你在本App建立的套路、練習紀錄、影片與音檔，全部只儲存在你的裝置(瀏覽器)裡。 不會自動傳送到開發者的伺服器，開發者也無法看到其內容。

資訊會被送到外部的，只有下列情況。
  • 使用者自己送出「意見與功能建議」時
  • 使用者自己建立帳號並登入時(帳號為選用)

1. 只儲存在裝置內的資訊

以下資訊儲存在瀏覽器的儲存區(IndexedDB・localStorage)，不會被送到外部。

  • 套路的編排(段落名稱、順序、音樂位置、風險度、A/B分支等)
  • 練習紀錄(全套的成敗、亂掉的位置、可能原因標籤、筆記、狀態等)
  • 段落影片、全套的表演影片、音檔、錄音
  • App的設定(顯示語言、影片畫質等)

這些都在裝置內，刪除瀏覽器資料或重設裝置就會遺失。 重要的紀錄請從App的「設定 → 完整備份」匯出ZIP檔，保管在裝置之外(電腦或雲端等)。

2. 會被送到外部的資訊

只有從App內「設定 → 意見與功能建議 → 傳送功能建議或問題回報」送出時，以下內容才會送給開發者。

送出的內容類型(建議／問題回報／其他)、輸入的本文、姓名(選填)、App版本、使用的瀏覽器與裝置資訊(User-Agent)、送出時間
不會送出的內容套路內容、練習紀錄、影片、音檔、錄音、筆記本文(寫進表單者除外)
使用目的重現與修正問題、檢討功能改善、必要時的聯絡
送到哪裡儲存在開發者管理的 Supabase(Supabase Inc.)資料庫。送出失敗時，會開啟你的郵件App，以寄給開發者的郵件送出。

表單中請勿輸入超出必要、能識別本人或第三人的資訊(真實姓名、聯絡方式、所屬單位等)。

3. 帳號（選用）

建立帳號為選用。不建立也能使用本App的全部功能。 帳號的用途是讓多台裝置能查看同一份紀錄。

取得的資訊電子郵件、密碼(儲存的是不可逆轉換後的值，開發者無法得知密碼本身)
使用目的本人確認、登入、密碼重設、裝置間同步資料的識別
保管位置Supabase(Supabase Inc.)的伺服器。本App指定東京區域
刪除方式希望刪除帳號時，請聯絡文末的窗口。刪除後，伺服器上的帳號資訊與已同步的資料將一併刪除

未登入的狀態下，不會送出任何帳號相關資訊。

4. 使用帳號時被儲存的內容（同步）

登入期間，下列資訊會在裝置間同步並儲存在Supabase的伺服器。不建立帳號就不會被送出。

會同步的內容套路的編排(段落名稱、順序、音樂位置、風險度、A/B分支等)、練習紀錄(全套成敗、亂掉的位置、可能原因標籤、筆記)、段落與音檔的資訊(名稱、長度等標頭資訊)
不會同步的內容影片、音檔與錄音的檔案本身、全套的表演影片、App的設定。這些只留在你的裝置裡
使用目的讓多台裝置能查看同一份紀錄
保管位置Supabase(Supabase Inc.)的伺服器。指定東京區域
刪除方式申請刪除帳號時，已同步的資料也會一併刪除

無法看到其他使用者的資料(伺服器端已限制只能存取自己的資料)。 紀錄中包含練習內容與筆記，請注意不要寫入不想讓第三人知道的內容。

5. Cookie與流量分析

本App不使用Cookie，也沒有導入廣告投放標籤。

為了瞭解使用情形，本App使用 Cloudflare Web Analytics。 這是不使用Cookie或localStorage等裝置端識別碼的方式， 也不會用IP位址或瀏覽器資訊來識別個人(指紋辨識)。 取得的只有頁面顯示次數、來源、瀏覽器與OS類型、大致的國家等統計資訊。

分析不會送出的內容

你建立的套路、練習紀錄、影片、音檔與筆記， 不會為了分析而被送出。

此外，本App的託管服務(GitHub Pages / GitHub, Inc.)可能在其端記錄連線IP位址等連線紀錄。

6. 提供第三人與委託

除法令要求外，不會將取得的資訊提供給第三人。營運上使用下列外部服務。

  • GitHub, Inc. — 本App的發佈(GitHub Pages)
  • Google LLC — 意見送出失敗時的預備管道(Gmail)
  • Cloudflare, Inc. — 使用情形分析(Web Analytics)
  • Supabase Inc. — 帳號的認證與保管、意見與建議的保存

7. 於國外的處理

上述各服務的伺服器可能位於日本國外(美國等)。 表單送出的資訊可能在這些國家保管與處理。

8. 保存期間

  • 裝置內的資料 … 由使用者自行管理。可隨時從App的「設定 → 重設」全部刪除。
  • 帳號資訊 … 帳號存在期間保管。收到刪除申請將盡速刪除。
  • 表單送出的內容 … 作為改善參考保管，不再需要時刪除。收到刪除申請將盡速刪除。

9. 資料的刪除方式

  • 裝置內的資料 … App的「設定 → 重設 → 刪除這台裝置的所有資料」
  • 已送出的意見與建議 … 請聯絡下方窗口
  • 帳號(電子郵件) … 請聯絡下方窗口

10. 未成年者的使用

本App的Beta版以18歲以上、或已取得監護人同意者為對象。 未滿18歲者，請務必取得監護人同意後使用。

11. 關於影片與音檔

錄製或登錄的影片與音檔只儲存在裝置內，不會傳送給開發者。 處理拍到第三人的影像時，請取得該人(未成年者則為其監護人)同意後使用。 關於權利的諮詢與刪除請求，請聯絡下方窗口。

12. 本政策的變更

本App為Beta版，可能隨功能的新增與變更修訂本政策。 重大變更時，會在本頁面公告。
