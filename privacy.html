ROUTINE NOTE — BETA

プライバシーポリシー

最終更新: 2026年7月27日 ／ 本サービスは現在ベータ版です

「ルーティンノート」（以下「本アプリ」）は、演技の通し練習を記録・分析するためのウェブアプリです。 本アプリにおける利用者情報の取り扱いについて、以下のとおり定めます。

まずお伝えしたいこと
本アプリで作成したルーティン・練習記録・動画・音源は、すべてお使いの端末（ブラウザ）の中だけに保存されます。 開発者のサーバーへ自動的に送信されることはなく、開発者がその内容を見ることもできません。

外部へ情報が送信されるのは、次の場合だけです。
  • 利用者ご自身が「ご意見・機能の要望」を送信したとき
  • 利用者ご自身がアカウントを作成・ログインしたとき（アカウントの作成は任意です）

1. 端末内にのみ保存される情報

以下は、お使いのブラウザの保存領域（IndexedDB・localStorage）に保存されます。外部へは送信されません。

  • ルーティンの構成（シーケンス名、順番、曲の位置、リスク度、A/B分岐など）
  • 練習の記録（通しの成否、崩れた箇所、原因の仮説タグ、メモ、体調などの記録）
  • 技の動画、通しの演技映像、音源、録音
  • アプリの設定（表示言語、動画の画質など）

これらは端末の中にあるため、ブラウザのデータを削除したり、端末を初期化したりすると失われます。 大切な記録は、アプリの「設定 → 完全バックアップ」からZIPファイルとして書き出し、端末の外（パソコンやクラウドなど）に保管してください。

2. 外部へ送信される情報

アプリ内の「設定 → ご意見・機能の要望 → 機能の要望・バグ報告を送る」から送信したときに限り、以下が開発者へ送信されます。

送信される内容種類（要望／バグ報告／その他）、入力された本文、お名前（任意・空欄可）、アプリのバージョン、ご利用のブラウザ・端末の情報（User-Agent）、送信日時
送信されないものルーティンの内容、練習記録、動画、音源、録音、メモ本文（フォームに書いた場合を除く）
利用目的不具合の再現と修正、機能改善の検討、必要な場合のご連絡
送信先Google Apps Script を経由し、開発者が管理する Google スプレッドシートに記録されます。送信先が未設定の期間は、お使いのメールアプリが起動し、開発者宛のメールとして送信されます。

フォームには、ご本人や第三者を特定できる情報（本名、連絡先、所属など）を必要以上に入力しないようお願いします。

3. アカウント（任意）

アカウントの作成は任意です。作らなくても、本アプリの全ての機能をご利用いただけます。 アカウントは、複数の端末で同じ記録を見られるようにするためのものです。

取得する情報メールアドレス、パスワード（保存されるのは元に戻せない形に変換した値で、開発者がパスワードそのものを知ることはできません）
利用目的本人確認、ログイン、パスワードの再設定、端末間でデータを同期するための識別
保管場所Supabase（Supabase Inc.）のサーバー。本アプリでは東京リージョンを指定しています
削除方法アカウントの削除をご希望の場合は、下記の問い合わせ先へご連絡ください。削除すると、サーバー上のアカウント情報と、同期していたデータを削除します

ログインしていない状態では、アカウントに関する情報は一切送信されません。

4. アカウントを使ったときに保存される内容（同期）

ログインしている間、次の情報が端末間で同期され、Supabaseのサーバーに保存されます。 アカウントを作らない場合、これらが送信されることはありません。

同期されるものルーティンの構成（シーケンス名、順番、曲の位置、リスク度、A/B分岐など）、練習の記録（通しの成否、崩れた箇所、原因の仮説タグ、メモ）、シーケンス（技）と音源の情報（名前・長さなどの見出し情報）
同期されないもの動画・音源・録音のファイルそのもの、通しの演技映像、アプリの設定。これらはお使いの端末の中だけに残ります
利用目的複数の端末で同じ記録を見られるようにするため
保管場所Supabase（Supabase Inc.）のサーバー。東京リージョンを指定しています
削除方法アカウントの削除をご依頼いただくと、同期されたデータもあわせて削除します

他の利用者のデータを見ることはできません（サーバー側で、ご自身のデータだけにアクセスを限定しています）。 なお、記録には練習内容やメモが含まれます。第三者に知られたくない内容を書き込まないようご注意ください。

5. Cookie・アクセス解析

本アプリは Cookie を使用しておらず、アクセス解析ツールや広告配信タグも導入していません。 ただし、本アプリを配信しているホスティング事業者（GitHub Pages / GitHub, Inc.）において、 接続元IPアドレスなどの接続記録が事業者側で記録される場合があります。

6. 第三者提供と委託

取得した情報を、法令に基づく場合を除き、第三者へ提供することはありません。 運営のために以下の外部サービスを利用しています。

  • GitHub, Inc. — 本アプリの配信（GitHub Pages）
  • Google LLC — ご意見・要望フォームの受け取りと保管（Apps Script / スプレッドシート / Gmail）
  • Supabase Inc. — アカウントの認証と保管（アカウントを作成した場合のみ）

7. 国外での取り扱い

上記の各サービスのサーバーは、日本国外（米国など）に所在する場合があります。 フォームから送信された情報は、これらの国において保管・処理されることがあります。

8. 保存期間

  • 端末内のデータ … 利用者ご自身が管理します。アプリの「設定 → 初期化」からいつでも全て削除できます。
  • アカウント情報 … アカウントが存在する間は保管します。削除のご依頼があれば速やかに削除します。
  • フォームから送信された内容 … 改善の参考として保管し、不要になった時点で削除します。削除のご依頼があった場合は、速やかに削除します。

9. データの削除方法

  • 端末内のデータ … アプリの「設定 → 初期化 → この端末のデータを全て削除」
  • 送信済みのご意見・要望 … 下記の問い合わせ先へご連絡ください
  • アカウント（メールアドレス）… 下記の問い合わせ先へご連絡ください

10. 未成年の方の利用

本アプリのベータ版は、18歳以上の方、または保護者の同意を得た方を対象としています。 18歳未満の方は、必ず保護者の同意を得たうえでご利用ください。

11. 動画・音源について

撮影・登録された動画や音源は端末内にのみ保存され、開発者へ送信されることはありません。 第三者が映り込む映像を扱う場合は、その方（未成年の場合は保護者）の同意を得たうえでご利用ください。 権利に関するご相談・削除のご依頼は、下記の問い合わせ先で承ります。

12. 本ポリシーの変更

本アプリはベータ版であり、機能の追加・変更に伴って本ポリシーを改定する場合があります。 重要な変更を行う場合は、本ページ上でお知らせします。
