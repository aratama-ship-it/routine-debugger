ROUTINE NOTE — DATA

如何保護資料

最後更新：2026年7月28日 ／ Beta版

1. 帳號與同步

不建立帳號時，資料只儲存在這個瀏覽器裡。 資料不會被傳到開發者的伺服器，但也不會和其他裝置共享； 清除瀏覽器的儲存資料，它們就會遺失。

建立帳號後，影片與音檔以外的資料會在線上管理。 因此可以在其他裝置同步使用。

影片與音檔的資料，目前不會在線上同步。 想把影片和音樂也帶到其他裝置時，請使用ZIP的匯出與匯入。

影片的雲端儲存，預計在Beta版之後的階段支援。

2. 不登入時的風險

未登入的狀態下，資料遺失的可能性會變高。

因為你做的東西只存在這個瀏覽器裡。 下面任何一件事發生，組好的編排和練習紀錄就再也找不回來了。

發生的事 未登入 登入中
執行了瀏覽器的「清除瀏覽記錄與網站資料」 全部遺失 編排與紀錄可以找回
裝置空間不足，瀏覽器自動清除了資料 全部遺失 編排與紀錄可以找回
iPhone長期沒開啟，儲存資料被清掉 全部遺失 編排與紀錄可以找回
使用無痕瀏覽 關閉分頁
就消失		 編排與紀錄可以找回
裝置遺失、損壞或換新機 全部遺失 編排與紀錄可以找回

只要登入，至少編排與練習紀錄可以在其他裝置找回。 但影片與音檔即使登入也不會回來。要連這些一起保住，需要完整備份ZIP。

另外，第2項因為「資料保護」會自動開啟而較不容易發生。 第3項只要加入主畫面，就幾乎可以避免。

3. 如何做完整備份

  1. 設定 → 完整備份 → 「匯出ZIP」 依影片數量可能需要幾分鐘。請保持在該畫面。
  2. 把產生的檔案移到裝置之外 iCloud Drive、Google雲端硬碟、電腦等。 放在同一台裝置裡，裝置遺失時會一起消失。
  3. 用「驗證ZIP（不還原）」確認內容 不用還原就能檢查匯出的檔案是否損壞。 會逐一比對每個檔案的內容，真正需要時能不能還原，在這裡就能知道。 這是為了避免「以為備份好了，其實檔案壞了」的事故。

建議在大幅修改編排之後，以及錄下重要的全套之後備份一次。

4. 還原時

登入中還原請特別注意

在登入狀態下從ZIP還原，內容也會同步到其他裝置。 備份裡沒有的套路和紀錄，會從其他裝置一併消失。
只想還原這台裝置時，請先登出再還原。

還原的位置是「設定 → 完整備份 → 從ZIP還原」。 還原前會比對所有檔案的內容，只要有一個損壞就會中途停止，不會置換任何資料。 不會發生只有一部分被改寫的情況。

請記住這件事

儲存空間依瀏覽器、依網站各自獨立。 用別的瀏覽器開啟，即使是同一台裝置，內容也是空的。請固定從同一個入口開啟。 加入主畫面就不會弄錯。

5. 遇到問題時

  • 匯出一直沒完成 … 影片多時需要時間。請不要切換畫面，稍候片刻
  • 還原時顯示「已損壞」 … 檔案可能在傳輸途中缺損。請重新匯出一次
  • 紀錄不見了 … 這是我們最想知道的問題。請用下方按鈕聯絡我們
