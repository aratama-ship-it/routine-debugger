テストへのご協力ありがとうございます

ルーティンノートは、演技を通すたびに「次に練習する場所」が決まるノートです。 まずは15分だけ、下の流れを試してみてください。

最終更新: 2026年7月25日 ／ ベータ版

アプリを開く

最初にお願い（大切です）
データはお使いの端末の中だけに保存されます。開発者側には残りません。 ブラウザの状態によっては消えてしまうことがあるため、 練習の記録が貯まってきたら「設定 → 完全バックアップ → ZIPで書き出す」を実行し、 ファイルをiCloudやパソコンなど端末の外に保存してください。
あわせて「設定 → データの保護 → 保護を有効にする」も押しておくと、消えにくくなります。

15分ミッション

この順に触っていただけると、確認したいところがひと通りカバーできます。

  1. ホーム画面に追加する Safariの共有ボタン →「ホーム画面に追加」。そこから起動すると、アプリのように全画面で動きます。
  2. サンプルを読み込んで、一周ながめる ルーティン一覧の「サンプル一式を読み込む」。技9本・楽曲・40通し分の記録が入るので、完成形のイメージがつかめます。
  3. 自分の曲でルーティンを1本つくる 「＋新規ルーティン」→ 技名を並べる → 音源を添付。ここが一番の山場です。迷った場所を覚えておいてください。
  4. 通し練習を2本記録する（クリーン1本・ミス1本） 「練習」→ セッションを準備 → スタート。崩れたら、その技の「ミス記録」をタップ。うまく通せたら「完走」。
  5. 分析を見る 「分析」で、どの技が何回・何％崩れたかを確認。見て意味が分かるかを教えてください。
  6. パート練習で気になる部分を繰り返す A/B区間をドラッグして指定 → ループ再生。再生速度も変えられます。
  7. 完全バックアップZIPを書き出して、検証する 「設定 → 完全バックアップ」で書き出し →「ZIPを検証する」で中身が無事か確認。ここは特に重点的に見ています。
  8. アプリを完全に閉じて、開き直す 記録が残っているか確認してください。消えていたら、それが一番知りたい不具合です。

特に教えてほしいこと

  • 止まった場所 … 「どうすればいいか分からなくなった」画面はどこですか
  • 面倒だった場所 … 準備に時間がかかった、タップの回数が多いと感じた場所
  • 壊れた場所 … 記録が消えた、動画が再生できない、固まった、など
  • 自分の曲で最初の1本を通せるまで、どれくらい時間がかかったか
  • 分析画面を見て、次に練習する場所が決まったかどうか

うまく言葉にできなくても大丈夫です。「なんとなく使いにくい」だけでも十分助かります。

いま分かっている制約

  • JSONバックアップには動画・音源が含まれません。動画も残したい場合は「完全バックアップ（ZIP）」を使ってください。
  • 通しの演技映像は最大5本まで保存できます（6本目を撮ると古いものと入れ替わります）。
  • iPhoneは、長期間アプリを使わないとブラウザの保存データを消すことがあります。「データの保護」を有効にしてください。
  • 初回はオンラインで開いてください。一度読み込めば、その後はオフラインでも動きます。
  • サブスク（Apple Music / Spotify 等）の曲は使えません。手元の音源ファイルをご利用ください。
  • ベータ版のため、予告なく画面や機能が変わることがあります。

フィードバックの送り方

アプリ内の 「設定（右上の歯車） → ご意見・機能の要望 → 機能の要望・バグ報告を送る」 から送れます。 種類（要望／バグ報告／その他）を選んで、気づいたことを書いてください。お名前は任意です。

送信時には、内容のほかにアプリのバージョンと端末の種類が一緒に送られます（不具合の再現に使います）。
ルーティンの内容・動画・音源が送られることはありません。詳しくはプライバシーポリシーをご覧ください。

直接のご連絡でも構いません: circusarata@gmail.com

困ったとき

  • 動きが変になった … 一度アプリを閉じて開き直してください。直らなければ、その状況を教えてください。
  • 最初からやり直したい … 「設定 → 初期化」で全て消せます（元に戻せません。必要ならバックアップを先に）。
  • データを消してほしい … 端末内のデータは上記の初期化で消えます。送信済みのご意見の削除は、上記メールへご連絡ください。
