ROUTINE NOTE — BETA

感謝你協助測試

Routine Note 是一本每跑一次全套，就決定「下一個要練的地方」的筆記。 請先花15分鐘，照下面的流程試試看。

最後更新：2026年7月25日 ／ Beta版

這個App能做什麼

從組出演目、練習到保存。請先從這些功能開始試。

配合音樂組出編排
  • 排列段落與銜接，組成一支完整的演目
  • 登錄音樂後，可以指定每個段落「在曲子的第幾秒」
  • 時間軸能一眼看出編排與音樂的對應，播放時目前位置也會移動
  • 音樂可以只截取想用的區間使用
累積素材
  • 段落可以存成短影片(排進編排就能直接用)
  • 音檔也能登錄到音檔庫。麥克風錄音與內附範例都可使用
練習
  • 5秒倒數後音樂自動播放，準備好就能直接進全套
  • 在意的部分可以指定A/B區間循環練習
  • 全套練習可以直接錄影(會自動與音檔合成)
持續養成
  • 改動編排會存成不同版本(v1・v2…)，可以比較改動前後
  • 連影片與音檔都能備份成1個ZIP
還可以做這些
記錄全套中亂掉的位置，分析各段落的失誤率／從長影片一次切出多個段落／ 分段練習可變速(音高不變)／A/B分支(正式演出時二選一的步驟)／ 風險度／日文・英文・繁體中文切換

A/B分支與風險度預設是隱藏的，需要的人才開啟。 從套路畫面右上的「套路」設定可以打開。

開啟App

一開始先拜託你這件事（很重要）
影片、音檔與錄音只儲存在你的裝置裡(登入也不會上傳)。 清除瀏覽器資料後，這些就找不回來了。
練習紀錄累積起來後，請執行「設定 → 完整備份 → 匯出ZIP」， 把檔案放到iCloud或電腦等裝置以外的地方。連影片都能保留的只有這個方法。
詳細寫在如何保護資料。
另外，防止空間不足時被自動清除的「資料保護」，會在產生紀錄時自動開啟 (狀態可在「設定 → 資料 → 資料保護」確認)。

15分鐘任務

照這個順序操作，就能把我們想確認的地方走過一遍。

  1. 加入主畫面 Safari的分享按鈕 →「加入主畫面」。從那裡啟動，就會像App一樣全螢幕運作。
  2. 載入範例，繞一圈看看 套路清單的「載入範例套路」。會載入範例段落、音樂與40次全套的紀錄，能掌握完成後的樣子。
  3. 用自己的音樂建立一支套路 「＋新套路」→ 排段落名稱 → 附加音檔。這是最大的關卡。請記下讓你猶豫的地方。
  4. 記錄兩次全套（零失誤1次、有失誤1次） 「練習」→ 準備本次練習 → 開始。亂掉就點該段落的「記錄失誤」；順利跑完就按「完成整套」。
  5. 看分析 在「分析」確認哪個段落亂了幾次、幾%。請告訴我們看不看得懂。
  6. 用分段練習重複在意的部分 拖曳指定A/B區間 → 循環播放。播放速度也能調整。
  7. 匯出完整備份ZIP並驗證 「設定 → 完整備份」匯出 →「驗證ZIP」確認內容完好。這裡是我們特別想測的部分。
  8. 完全關閉App後再開啟 確認紀錄是否還在。如果消失了，那正是我們最想知道的問題。

特別想聽的回饋

  • 卡住的地方 … 在哪個畫面「不知道該怎麼辦」
  • 覺得麻煩的地方 … 準備太花時間、覺得點太多下的地方
  • 壞掉的地方 … 紀錄消失、影片無法播放、畫面卡死等
  • 用自己的音樂跑完第一次全套，花了多少時間
  • 看了分析畫面，有沒有決定出下一個要練的地方

不必說得很精確。「總覺得不好用」這樣的回饋也非常有幫助。

目前已知的限制

  • 備份只有「完整備份(ZIP)」一種。影片與音檔都包含在這一個檔案裡。
  • 全套的表演影片最多保存5段(錄第6段時會與舊的交換)。
  • iPhone長期不使用時，瀏覽器可能清除儲存資料。加入主畫面即可幾乎避免。
  • 第一次請在連線狀態下開啟。載入一次後，之後離線也能使用。
  • 串流訂閱(Apple Music / Spotify等)的音樂無法使用，請用手邊的音訊檔。
  • 帳號(設定 → 帳號)不是必須的。不建立也能免費使用全部功能。 登入後，套路與練習紀錄會在裝置間同步(影片與音檔只留在該裝置)。
  • 因為是Beta版，畫面與功能可能不經預告而變動。

如何傳送回饋

從App內的「設定(右上齒輪) → 意見與功能建議 → 傳送功能建議或問題回報」即可。 選擇類型(建議／問題回報／其他)，寫下你注意到的事。姓名可留空。

送出時，除了內容之外也會附上App版本與裝置類型(用於重現問題)。
套路內容、影片與音檔不會被送出。
另外，為了瞭解使用情形，我們使用了不依賴Cookie的流量分析 (Cloudflare Web Analytics)，同樣不會送出套路內容。 詳見隱私權政策。

遇到問題時

  • 動作變得怪怪的 … 請先關閉App再開啟。若沒有恢復，請告訴我們當時的狀況。
  • 想從頭來過 … 「設定 → 重設」可全部刪除(無法復原。需要的話請先備份)。
  • 想刪除資料 … 裝置內的資料用上述重設即可刪除。已送出的意見要刪除，請寄信到上述信箱。
